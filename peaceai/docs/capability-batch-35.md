## Families

`normalizePath` stripped a leading `./` after collapsing slashes, so a path used for requiring a module lost that prefix. `jonschlinkert/normalize-path` at parent `5563c9c3a0dabf5648d7ec9c3cfbcca405a04276` does that in `index.js`. Commit `e6e5d7dafcadd816df87a14021dab065a7d987fc` keeps the leading `./`. The published `test.js` fails the `./foo/bar/baz/` case (`'foo/bar/baz/' == './foo/bar/baz/'`), and passes after the edit.

`word-wrap` called `.join` on the result of `String#match` without a fallback, so a string of only newlines threw. `jonschlinkert/word-wrap` at parent `1ebbc454c92f9a133f3354e2896d49142a568242` does that in `index.js`. Commit `59800542abf0b42e377208405703c68786cd1290` treats a missing match as an empty list. The published `test.js` fails the newline-only case (`TypeError: Cannot read properties of null (reading 'join')`), and passes after the edit.

A long option followed by a lone `-` was treated as a new flag, so `--nnn -` did not keep `-` as the option value. `minimistjs/minimist` at parent `72239e6f0ea77d8be0ad4f682b7ae7d142144395` does that in `index.js`. Commit `63b8fee87b8e7a003216d5d77ba5d6decf3cfb0d` accepts a lone dash as a value. The published `test/dash.js` fails the long-option dash cases (`expected { nnn: '-' }` / `{ nnn: '---' }`), and passes after the edit.
