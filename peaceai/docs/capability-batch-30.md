## Families

`createAtom` left the active subscription set while a subscriber ran, so an observer that read another atom became subscribed to it and fired again. `TanStack/store` at parent `4fa67bb1a0f9bfef906e6fb2849cc47b2a5baa4d` does that in `packages/store/src/atom.ts`. Commit `e06c28cbdf3514c4edd5dfc29c4d05e396363605` clears `activeSub` before the observer runs. The published `packages/store/tests/observer-isolation.test.ts` fails those cases, and passes after the edit.

`Request` is a lightweight subclass of the native `Request`, so a native `GlobalRequest` was not `instanceof Request`. `honojs/node-server` at parent `348e88587ae1f0d2a53d26fdd8c16e54c7db5d2b` does that in `src/request.ts`. Commit `9f7a5cbf68dff5cb7f6ed3aded98c6ff3ee4802a` adds `Symbol.hasInstance` so a native request matches, while a further subclass still uses the default brand. The published `test/request.test.ts` fails that case, and passes after the edit.

`runNpmScript` always tried to read `package.json` when scripts were not ignored, so a version bump in a directory with no manifest threw `ENOENT`. `antfu/bumpp` at parent `fa0f433a6fd77a1173f10d7c696e7090b6d3972d` does that in `src/run-npm-script.ts`. Commit `aa3fc86e3bb152dda8627a7fe156acb45f800ca8` skips the scripts when `package.json` is missing. The published `test/run-npm-script.test.ts` fails that case, and passes after the edit.
