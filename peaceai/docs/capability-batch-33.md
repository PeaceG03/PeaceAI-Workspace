## Families

`areInputsEqual` used `!==` on each argument, so a second call with `NaN` looked like a new input and the memoized function ran again. `alexreardon/memoize-one` at parent `2f875cac31ef8ce64112a4f9226684e521f9e2a9` does that in `src/are-inputs-equal.ts`. Commit `8109d454dc65585a13eb2d8db937395116c24338` treats two NaN values as equal. The published `test/memoize-one.spec.ts` fails the NaN cases (`Expected number of calls: 1, Received number of calls: 2`), and passes after the edit.

`readFile` only swallowed `ENOENT`, so a directory whose name matched a search place (`package.json` as a folder) threw `EISDIR` and stopped the search. `cosmiconfig/cosmiconfig` at parent `18346056c9a7fdf8d7531ea5a998edfb255fc140` does that in `src/readFile.ts`. Commit `f6980541371db31174bd92958e3b2f7fc4ff6412` also treats `EISDIR` as a missing file. The published `test/successful-directories.test.ts` fails the directory-named-as-search-place cases (`EISDIR: illegal operation on a directory, read`), and passes after the edit.

`Cache.getKeyIndex` read `this.keys[0].length` when the cache was empty, so an empty cache threw instead of returning -1. `planttheidea/micro-memoize` at parent `b3d8f2ae1ec3c3cee1926d78b85b8a56a08b5df3` does that in `src/Cache.ts`. Commit `52ee826eeb19d5f2cfa1ddedc93f5818a8c43c4a` returns -1 when there are no keys. The published `__tests__/Cache.ts` fails the empty-cache cases (TypeError reading `length` of undefined), and passes after the edit.
